# Weather-aap-Nikita-🌤️ Weather App

A simple and responsive Weather App that lets users search for any city and view current weather information in real time.

✨ Features

* 🌍 Search weather by city name
* 🌡️ Current temperature
* ☁️ Weather condition
* 💧 Humidity
* 💨 Wind speed
* 🌅 Sunrise & sunset information
* 📱 Responsive design for mobile and desktop
* 🔄 Real-time weather data using a weather API
* ⚠️ Error handling for invalid city names

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Weather API
* Responsive Web Design

🚀 Getting Started

1. Clone the repository

git clone https://github.com/your-username/weather-app.git

2. Open the project

cd weather-app

3. Configure the API

Get an API key from your weather API provider and add it to your JavaScript configuration.

const API_KEY = "YOUR_API_KEY";

4. Run the app

Open index.html in your browser.
